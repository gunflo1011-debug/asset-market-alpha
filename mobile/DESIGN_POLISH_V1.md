# Product polish v1

Design direction: premium asset manager with a lightweight private marketplace.

Priorities:
- inventory first: compact, scannable, value-led
- detail second: one clear hierarchy for value, details and selling
- marketplace: price-first cards with minimal metadata and privacy reassurance
- selling: one focused asking-price flow with explicit publish consent
- restrained visual system: off-white surfaces, deep navy primary actions, green only for safe/private/live states, red only for destructive actions

This milestone intentionally changes presentation and interaction density without changing the authenticated ownership, value, marketplace or privacy contracts.
